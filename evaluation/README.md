# Golden Dataset 작성 가이드 (MILESTONE 4)

AI 분석 결과(`ai_analysis`)의 정확도를 측정하기 위한 기준값을 사람이 직접 작성한다. (README §13)

## 파일

| 파일 | 용도 |
|---|---|
| `worksheet.md` | 공고별 **AI 입력 텍스트**. 이것만 보고 작성한다 |
| `golden-dataset.json` | 기준값. 여기에 작성한다 |

## 작성 원칙

1. **AI 입력 텍스트(worksheet.md)만 근거로 쓴다.**
   기업마당 웹페이지·첨부 PDF 에 정보가 더 있어도 쓰지 않는다. AI 는 그 내용을 받지 못했다.
2. **AI 결과를 보지 않고 쓴다.** API 응답이나 DB 의 `ai_analysis` 를 먼저 보면 판단이 끌려간다.
3. 텍스트에 없거나 판단이 애매하면 "없음"(빈 배열·null)으로 두고 `note` 에 이유를 쓴다.
4. 한 건을 다 쓰면 `"labeled": true` 로 바꾼다. `false` 인 항목은 평가에서 제외된다.

## 필드별 기준

### regions — 신청 기업의 소재지 조건

- 값: `서울 부산 대구 인천 전남광주 대전 울산 세종 경기 강원 충북 충남 전북 경북 경남 제주 전국`
- **신청 자격으로서의 소재지 조건**이 텍스트에 있을 때만 쓴다.
  - "포항시 관내에서 사업장을 운영 중인 소상공인" → `["경북"]`
  - 시·군·구는 소속 시·도로 쓴다. 김해시 → `경남`
  - 광주광역시·전라남도 → `전남광주` (기업마당 표기)
- 신청자의 **사업장·점포·본사·주소·농지** 등이 특정 지역에 있어야 하면 그 시·도를 쓴다. "관내 ○○" 표현도 포함한다.
  - "강구안 상권 대상지 내 상인" → `["경남"]`, "관내 농지를 소유한 농업인"(상주시) → `["경북"]`, "대전산업단지에 소재하는 기업" → `["대전"]`
- 공고명 접두어(`[경남]`)나 소관기관만으로는 쓰지 않는다. 주최 지역이지 자격 조건이 아니다.
- "전국", "지역 제한 없음"이 **명시**되었을 때만 `["전국"]`. 언급이 없으면 `[]`.

### businessAge — 업력(창업 후 경과 연수) 조건

- `{"minYears": 정수|null, "maxYears": 정수|null}`
  - "창업 7년 이내" → `{"minYears": null, "maxYears": 7}`
  - "업력 7년 이상" → `{"minYears": 7, "maxYears": null}`
  - "3년 이상 7년 미만" → `{"minYears": 3, "maxYears": 7}` (이하/미만은 구분하지 않는다. 스키마 한계 — `note` 에 기록)
- 업력 조건이 없으면 둘 다 null. "예비창업자"는 업력이 아니라 applicantTypes 로 본다.

### maxAmount — 기업당 최대 지원금액 (원)

- 원 단위 정수. "5천만원" → `50000000`, "최대 2.0~7.5억원" → `750000000`
- 트랙·유형이 여러 개면 **가장 큰 값**.
- 사업 전체 예산(총 사업비, "총 10억원 규모")은 기업당 금액이 아니므로 쓰지 않는다.
- 융자 한도도 "지원 한도"로 본다.
- 현물·서비스 지원(광고, 컨설팅)처럼 금액이 없으면 null.

### applicantTypes — 신청 가능한 기업 형태

- 값: `SOLE_PROPRIETOR`(개인사업자), `CORPORATION`(법인), `PRE_FOUNDER`(예비창업자)
- 텍스트에 **명시**된 것만. "중소기업", "소상공인"만 있으면 형태가 명시되지 않은 것이므로 `[]`.

### applicationStart / applicationEnd — 신청기간 (AI 평가 아님)

- `"YYYY-MM-DD"` 또는 null. `[신청기간]` 기준.
- "예산 소진시까지", "상시 접수" → 둘 다 null.
- 이 값은 AI 가 아니라 기업마당 API 값을 Java 가 파싱한 결과(`support_program.application_start/end`)와 비교한다.

## 평가 방법

```
GET /api/admin/evaluation?promptVersion=v1
```

| 항목 | 일치 기준 |
|---|---|
| 지역 | 집합 일치 |
| 업력 | min, max 모두 일치 (null = null) |
| 지원금 | 값 일치 (null = null) |
| 기업 형태 | 집합 일치 |
| 신청기간 (규칙 기반) | 시작일·종료일 모두 일치 |
| Evidence 포함률 | AI 가 값을 추출한 항목 중 근거 문장이 있는 비율 |
| Structured Output 성공률 | COMPLETED ÷ (COMPLETED + INVALID_JSON + VALIDATION_ERROR). Gemini 과부하·한도 등 인프라 실패는 제외 |
